# A2 local-recovery tuning budget pilot

This development pilot begins at the accepted PR 58 merge. The completed
spatial and temporal experiments and a2 parameter-selection result provide
its prior evidence. The historical empirical a2 comparator sampled frames.
This pilot compares one-state AR with contiguous empirical donor windows
for weight selection at limited labelled-outing budgets.

## Partition and support

Use the first of seven accepted outer folds in stable held-out outing ID
order. Identify the outer training outings from the original sealed
experiment. The latest registered archive locator and row manifest are
pinned through that experiment. A separate digest binds the seven
outing/archive pairs to the accepted a2 selection manifest. The reader
resolves the other six archives and has no route to the outer held
numeric object. This is a selective consumer of the accepted checkpoint.

Reserve the last of the six outer training outings for an inner
development audit. Use the first 1, 3 and 5 of the other outings as
labelled budgets. Fit subset-specific transforms, the conditional Gaussian
base and the existing free-running one-state AR independently for each
budget. Structure, fit recipe and original sequence boundaries follow
the accepted model. These stages operate on processed archives.

From each calibration outing, choose 12 eligible whole sequence contexts
at evenly spaced indices in source order as in a2. The pilot shares
those covariates across budgets. It measures labelled residual training
needs with a common covariate bank. For the empirical arm, sample a donor
outing, eligible donor sequence and eligible contiguous window uniformly
at each level. Use the target frame length and a 20 ms maximum per-step
clock difference. Apply the original target intervals during rollout.
Every window stays within a donor sequence. Report support by outing,
context and budget. Both arms use the intersection of supported
calibration contexts across budgets.

## Three stages

| Stage | Data opened | Published result |
|---|---|---|
| `preflight` | Pinned metadata and calibration conditions, source clocks, stations and offsets | Immutable preparation receipt with roles, resource counts, common donor support, nominal diagnostics and feasible weights |
| `select` | Preflight input set plus calibration residual arrays as nested budgets are admitted | Subset-specific fit and sampling receipts, risk curves, 32/64 choices and choice seal |
| `audit` | Frozen-choice metadata and the inner audit archive | Paired observed loss, nominal outcomes and descriptive contrasts |

Preflight hashes calibration NPZ files for identity and decodes
allowlisted metadata members only. The stage diagnoses missing common
support, native model resource bounds and the a2 nominal feasibility gate
with zero disturbance. Use nine accepted curvature settings, the same
four tasks, the 20% outing-mean tracking allowance and the passive
recovery probes. Preserve a stop if fewer than two candidates are
feasible or if the reference fails the nominal envelope. There is no
population-law discrimination requirement in this gate.

Selection validates the pinned preflight and reconstructs the same
panel before reading labels. Use 64 draws with the first 32 as the
earlier stability diagnostic. Score the same panels and fixed nominally
feasible grid for both arms. Aggregate by equal tasks and draws,
sequences and then calibration outings. Keep the a2 tie rule. Record
wall time, process peak memory, native fit warnings, convergence and
scope. Preserve any failed budget alongside completed panels. Missing
choices stop the audit stage. All writes are exclusive so a previous
attempt remains recoverable as evidence.

Audit checks the choice hash before opening the inner audit numeric
archive. Choose up to 12 eligible sequences by source order using
covariates and clocks, then load the observed labels. Apply each frozen
setting to the same observed profiles with the original a2 loss and
timing. Report its observed loss minus the five-outing empirical
selection loss and the AR-minus-empirical contrast at each equal budget.
The 2% descriptive band and nominal checks are reported separately.
Prepare a choice-independent full assessment and separate validation
before drawing a data-efficiency conclusion across outings. A stable
small-budget tie is informative for this pilot and stays in the record.

The accepted a2 study and this pilot operate on local recovery with
exogenous disturbances. Physical frame reconstruction remains an
optional extension for a stronger recorded-replay claim. Retain the
failed synthetic receipts and existing data and source evidence.
The independent confirmation of final datasets, data roles and paper
claims remains future work.
