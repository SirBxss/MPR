## Boundaries and unchanged science

- `domain.numeric_export` fixes the revision, immutable admission description,
  closed schemas and U48 archive construction. The target, sign, H100 grid,
  six features and sequence rules are unchanged.
- `io.numeric_export_inputs` checks bounded strict JSON, exact registration
  membership, old inventory/decode validation, complete readiness shapes,
  lineage/source identity and exact whole-batch authorization. Its registration
  reader does not resolve, stat or open raw paths, so validation works after
  raw is unavailable. Metadata files are bounded regular non-symlinks.
- `io.numeric_residuals.NumericObserver` composes around the unchanged
  `ScientificSink`. It delegates the original objects/arguments once, observes
  detached scalars, checks sink position/one append/exact clock and selects
  declared KEEP_LANE. No new admission/conversion helper is imported or called.
  Confidence length does not invoke confidence-value validation.
- Scalar observation uses a table on the existing science connection and
  counts against its existing cap. Ordinary extraction errors receive one
  static first-failure code per message. Workflow, memory, storage, checkpoint
  and real sink/reader failures are outside that containment boundary.
- After full fresh stream/binding/readiness equality, a diagnostics-free staged
  pass reproduces counts/support/conditions without another raw read. Only
  then is the existing `aligned_residual` used. Only `residual_non_finite` can
  exclude a row; geometry contradictions and unexpected failures null the batch.
- `io.numeric_archive` validates exact schema, policies, artifact hashes,
  candidate mappings, exposure, clocks, bracket/log evidence and both support
  populations. Its sequence reconstruction is separate from the exporter.
  ZIP/NPY member, header, shape, dtype, order, compressed/uncompressed bounds,
  CRC and trailing-stream checks precede NumPy loading with pickle disabled.
- `workflows.numeric_export` owns raw verification, resources, late input/raw
  states and publication. Inputs are rechecked across validation/publication,
  including earlier files. A later failure cannot publish an earlier subset.

The five shared scientific source files match accepted main byte for byte.
Tests pin their hashes, the complete seven keyword uses and four default-False
definitions. A new-module import/direct-call guard supplements runtime tests;
it is not a formal proof against arbitrary dynamic Python.

## Budgets and failure behavior

Existing 4 GiB process, 6 GiB available-memory, 512 MiB index/8 GiB science,
8.5 GiB combined SQLite and 1,800-second scientific budgets remain. Initial
scratch is 19.5 GiB, including the additional 1 GiB artifact reserve; runtime
scratch stays at 10 GiB. At most 100,000 advertised EDP messages are accepted
across the whole registration, not per recording times 64.

Audit/summary caps are 256/64 MiB; NPZ is capped at 128 MiB compressed and
uncompressed. Publication and standalone validation each have a 300-second
cap. Publication reserves five seconds inside that cap for an inconclusive
marker. Staging/destination must share checked scratch's device, both before
creation and on the created directory. All numeric work stays within the
existing per-recording deadline; serialization has its own bounded phase.

Preflight failure exits 2 without output. Complete export, including empty,
exits 0. Post-preflight failure exits 3 and normally publishes only an
inconclusive summary with null aggregate populations and false export flags.
If a deadline or storage error prevents even that failure marker, no completed
dataset is left and a static marker-unavailable diagnostic is logged. An
unrelated destination appearing during work is preserved. Cleanup removes only
owned files; absence of a complete summary is never a dataset.

Standalone validation writes one new receipt outside the archive/registration,
without raw access, model admission or deletion permission. Installation refuses
an existing receipt. Metadata/artifacts are checked again before its atomic
installation; incomplete temporary receipts are removed on failure.
